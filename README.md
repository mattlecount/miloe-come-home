# Miloe, Come Home

A Three.js audio-visual experience for the song about waiting to adopt Miloe.

## Live
https://miloe-come-home-webwax.vercel.app

## Assets needed
Place `miloe.m4a` (the audio track) and `miloe-photo.jpg` (the dog photo) in the root of this repo so they load with the experience. They will be picked up on the next deploy.

Click the start screen to begin. The scene reacts to the audio and progresses through the lyrics.
